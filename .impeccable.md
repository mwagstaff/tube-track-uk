## Design Context

### Users

London Underground passengers using an iPhone to understand the network quickly, especially while checking live service status, engineering works, delays, and affected station-to-station sections. The map must remain familiar at a glance and accessible through VoiceOver, Dynamic Type, and non-colour-only status cues.

### Brand Personality

Familiar, precise, and dependable. TubeTrack UK should feel like a calm, utilitarian transport instrument: visually confident without decoration, independent from TfL while respecting the established Tube-map visual language.

### Aesthetic Direction

Use the official TfL vector map as the visual authority for the Beck view. Preserve its authored geometry, octilinear structure, line ordering, station/interchange grammar, spacing, and manually positioned labels. Prefer the official light-map appearance as the fidelity baseline; dark mode may adapt presentation without changing network geometry. Avoid geographic layout, algorithmic schematic generation, ornamental effects, and generic map styling.

### Design Principles

1. Fidelity before invention: trace the official artwork and do not redesign or automatically optimise it.
2. Geometry is immutable presentation data: live status changes styling and overlays, never station or path positions.
3. Preserve semantic addressability: every adjacent station pair remains independently targetable for disruptions and engineering works.
4. Protect legibility: labels, line ticks, roundels, interchange connectors, and shared corridors must follow authored TfL-style spacing and never create false interchange relationships.
5. Verify visually and structurally: use deterministic assets, topology validation, protected label zones, and fixed-reference regression tests.
