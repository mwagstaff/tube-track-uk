## Design Context

### Users
London rail passengers using an iPhone to understand the network, check live service conditions, inspect stations and departures, and plan around disruption. The map must remain quickly legible while panning and zooming, including when connectivity is unavailable.

### Brand Personality
Clear, dependable, familiar. The experience should feel native to iOS while respecting the visual grammar passengers already know from Transport for London's diagrammatic maps.

### Aesthetic Direction
A precise, restrained transit interface led by the authored network map. Use official TfL map conventions as the primary reference for route geometry, 45-degree diagonals, station markers, interchange connectors, line colours, spacing and hierarchy. Support system light and dark appearance without decorative effects that compete with network information.

### Design Principles

1. Preserve instant network legibility: route relationships and station order take priority over geographic fidelity.
2. Follow the TfL diagram's geometric language: horizontal, vertical and 45-degree paths; compact, consistently aligned interchange connectors.
3. Keep station labels, roundels and line work optically balanced at every supported zoom level.
4. Stay native and inclusive: support Dynamic Type, VoiceOver, Reduce Motion and system appearance.
5. Prefer authored, regression-tested geometry over one-off visual adjustments so map refinements remain stable.
