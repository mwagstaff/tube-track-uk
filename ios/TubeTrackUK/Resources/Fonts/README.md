# App fonts

TubeTrack UK bundles these typefaces under the SIL Open Font License 1.1:

- Cabin Regular, Medium, SemiBold, and Bold from the Cabin project, pinned to commit `70efa8c3179359cc50b01ca184fec8a694156140`.
- Metropolitan Line Regular `v1.003` from the Metropolitan Line project.

The corresponding license texts are stored beside the font files.

Cabin is used for interface and supporting text. Metropolitan Line is used for headings and display titles.
