# TubeTrack UK — Product Design Specification (PDS)

This companion document expands the implementation brief with UX, interaction and visual guidance.

## Vision

- Apple Maps × Flighty × Citymapper inspiration
- Map-first experience
- Live status always visible
- Section-level disruption highlighting
- Liquid Glass design language

## Deliverables

1. Schematic Map
2. Real World Map
3. Engineering Works
4. About
5. Reusable design system
6. Animation guide
7. Component catalogue
8. Accessibility guidance
9. Network Health concept

## Schematic Map

- Harry Beck inspired vector rendering.
- Central London default viewport.
- Floating glass status panel.
- Issue Highlight mode greys unaffected network.
- Live train overlay with line filters.

## Real World Map

- MapKit base.
- Tube geometry overlays.
- Same interactions as schematic map.

## Engineering Works

Chronological glass cards grouped by weekend with coloured line accents.

## Design System

- GlassPanel
- GlassButton
- GlassChip
- StatusCard
- WorksCard
- LiveTrainMarker

## Animation

- Spring for panels.
- Ease-in-out for issue highlighting.
- Smooth interpolation for trains.

## Network Health

Circular summary showing overall Tube health and disruption count.
